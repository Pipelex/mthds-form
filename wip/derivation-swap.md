## The design, as decided (do not re-litigate)

- **`buildRunFields(descriptor, inputs)`** — new signature: the pipe's `PipeInputFormDescriptor` first, the contract's inputs map second. It maps the wire tree structurally; kinds, constraints, `required`/`presence`/`gating`, `refines`, `default_value`, `examples`, `hints`, `datetime`, `integer`, `choices`, number bounds (exclusive collapsed into `min`/`max`) all come from the wire verbatim. The contract's `json_schema` is co-walked for exactly two facts the wire deliberately omits: **`contentKey`** (structural rule: a scalar-kind node — text/prose/number/boolean — whose aligned schema resolves to an object declaring exactly one property) and **nested list bounds** (`minItems`/`maxItems`; top-level `itemCount` prefers the wire's `item_count`, `maxItemCount` prefers schema `maxItems`). `accept` strings are stamped as presentation defaults keyed on the wire kind. No schema fallback for kinds or bounds the wire states — the mapper decides nothing.
- **The gate never needs the descriptor.** Doctrine (carriage spec): a machine consumer never reads the presentation artifact to validate; `json_schema` keeps that job. So `gateRunInputs(contract, data)` keeps its signature and its emptiness re-check runs over a private structural schema walk — new module `src/core/gating-fields.ts` (object/list/leaf tree from exactly the keywords ajv enforces, `gating` stamped from `inputMustBeFilled`). Not exported. `gate-agreement.test.ts` is now the cross-tree agreement proof (wire-mapped readiness vs schema-walked gate) and passes.
- **`fieldsForContract(contract, descriptor)`** — second parameter added, `[]` unless both present. New export `getPipeInputForm(inputForm, domain, pipeCode)` in `derive.ts` — `getPipeIOContract`'s twin. Core index re-exports `InputForm`, `PipeInputFormDescriptor` types and `TextConstraints`.
- **`native-concepts.ts` deleted.** The wire-path survivors (bare/namespaced sets for Text and Document/Image/Page, the list-ref split) moved INTO `wire-format.ts` as private functions — the deflate/inflate taxonomy is a fact about the runtime's input parser, not rendering. `derive.ts` fully rewritten; heuristics gone.
- **`RunField` grew** (`descriptor.ts`): `refines`, `presence` (top-level only, like `gating`), `defaultValue`, `examples`, `hints` on common; `TextConstraints` (`minLength`/`maxLength`/`pattern`/`format`) on text/prose.
- **Test fixture idiom**: `contract-fixtures.ts` gained `WIRE_PLAIN` / `WIRE_FORCE` / `WIRE_VARIABLE` / `WIRE_OPTIONAL` (pipe-slot fact triples) and `descriptorOf(...)`. Suites hand-author the wire node beside each contract fixture (never derive it from the schema in test code). `gate-agreement` keys nodes by fixture identity in a `Map` so its row table stayed untouched.

## Reviewed behaviour differences (the characterization diff — goes into docs/derivation-swap.md rewrite)

1. **`native.Date`**: prose + `{text}` wrap + `{concept, content: {text}}` store → object node over `DateContent {date, time}`; store/wire now `{concept, content: {date, time}}`. Wire-visible; closes `L-260821-2e3730`. (Composite date control over the object node = allowed presentation call, NOT done — note as follow-up option.)
2. **`native.Html`**: renders object as before, now by wire declaration instead of the `HTML` spelling accident.
3. **A concept refining `native.Text`** (e.g. a Poem with the TextContent wrapper schema): was a nested object card; now `kind: prose` with `contentKey: 'text'` — runner value becomes a bare string; the STORED shape is unchanged (`{concept, content: {text}}`). values.test rewrite must flip those assertions.
4. **`TEXT_WRAPPER_CONCEPTS` fallback gone**: `native.Text` with a degenerate contract (bare `{type:'object'}` with no properties, or `{type:'string'}`) no longer gets a `{text}` contentKey — contentKey is purely structural now.
5. **Depth rule, url-bearing-object test, `maxLength>120` prose rule, schema-`enum` kind dispatch**: deleted; the wire states kinds. Number bounds no longer read from the schema at all (wire `minimum`/`maximum`/exclusives only).
6. **Field order** now the descriptor's authored order, not the inputs-map insertion order.
7. **`title`** now mapped from the wire (trustworthy — the engine never reports a model name as a title); it used to be suppressed.
